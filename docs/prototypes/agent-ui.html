Передать данные опроса ИИ?

ИИ-помощник работает через внешний сервис (OpenRouter). Ему будут переданы:

  • сводные цифры по вопросам и показатели опроса;
  • до 30 цитат из открытых ответов, телефоны и e-mail в них заменяются метками;
  • тексты вопросов анкеты.

Продолжая, вы подтверждаете, что вправе передавать эти данные: опрос анонимный или респонденты согласились на такую обработку. Решение запоминается для этого опроса.
