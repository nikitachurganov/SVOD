### Профиль, анкета первого входа, обучающий тур — `af9a4c2`
43 файла, +2813 / −41.
- **Профиль.** Страница «Профиль»: смена фамилии, имени, отчества и пароля (`PATCH /auth/me`, `POST /auth/me/password`). Неверный текущий пароль даёт 400, а не 401, чтобы клиент не принял это за конец сессии; после 5 неверных попыток за 15 минут — 429. Смена пароля гасит ссылки сброса. Страница открывается и у пользователя без организации.
- **Анкета первого входа.** Таблица `user_onboarding` (миграция `035`): кто пользуется сервисом, для чего, откуда узнал; статус и шаг обучения. Существующим аккаунтам анкету можно закрыть, новым — нет. Эндпоинты: `PUT /auth/me/onboarding`, `POST /auth/me/onboarding/dismiss`, `PATCH /auth/me/tour`.
- **Обучающий тур.** 12 шагов от создания проекта до ИИ-резюме. Пользователь делает настоящие действия, тур следит за ответами API и адресом и сам переходит дальше. Состояние хранится на сервере и в localStorage, повторный запуск из меню профиля.
- **Тестовые ответы.** `POST /surveys/{id}/demo-responses` создаёт правдоподобные ответы по схеме опроса (по правилам, без ИИ), только в опубликованный опрос без ответов. `DELETE` удаляет их и сбрасывает ИИ-резюме. Тесты: `test_profile_update.py`, `test_user_onboarding.py`, `test_survey_demo.py`.
