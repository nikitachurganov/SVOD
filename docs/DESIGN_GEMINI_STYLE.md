## 2. Принципы

1. **Тихая канва, белые острова.** Канва, шапка и сайдбар одного цвета. Контент — одна белая панель со скруглением 16. Рамок почти нет: границы задаются заливкой.
2. **Пилюли везде, где можно нажать.** Кнопки, чипы, пункты меню, сегменты, поле поиска.
3. **Тональная заливка вместо теней.** Выбранное — голубой `primary-container`, наведение — полупрозрачный слой. Тень — только у всплывающего (меню, поповер, пилюля ввода).
4. **Лёгкая типографика.** Заголовки крупные и `400`, полужирный `500` только у кнопок и названий.
5. **Один акцент.** Синий Google для действия, оранжевый СВОД — в логотипе (см. раздел 8).

## 4. Шрифт

- **Google Sans** — заголовки, кнопки, навигация. **Google Sans Text** — основной текст, таблицы, поля. Оба есть на Google Fonts с кириллицей (проверено 2026-11-09). У Google Sans Flex кириллицы пока нет — не берём.
- Подключение: `<link>` в `index.html` с `display=swap`. Запасной стек: `'Google Sans Text', Roboto, Inter, system-ui, sans-serif`.

## 6. Поверхности и тени

- Без теней: канва, панель, карточки, таблицы, сайдбар.
- Elevation 1 (пилюля ввода, кнопка «Создать», карточка при наведении): `0 1px 2px rgb(0 0 0 / .3), 0 1px 3px 1px rgb(0 0 0 / .15)`.
- Elevation 2 (меню, поповер, тост): `0 1px 2px rgb(0 0 0 / .3), 0 2px 6px 2px rgb(0 0 0 / .15)`.
- Elevation 3 (модалка): `0 4px 8px 3px rgb(0 0 0 / .15), 0 1px 3px rgb(0 0 0 / .3)`.
- Состояния — слой цвета текста поверх заливки: наведение 8 %, нажатие 12 %.
- Фокус клавиатуры — кольцо 2 px `primary` с отступом 2.

## 7. Компоненты

**Шапка.** Высота 64, фон канвы, без нижней рамки. Слева крошки (Title M), справа иконки-кнопки 40 и аватар 32. На телефоне — бургер, название, аватар.

**Сайдбар.** Ширина 280 (свёрнутый — 72, только иконки). Фон канвы, без рамки. Сверху логотип и кнопка «Создать опрос» — пилюля 56 с elevation 1, как «New» в Drive. Пункты — пилюли 40, активный `primary-container`. Разделы — Caption серым. Внизу рабочее пространство и тариф — тональная плитка 16.

**Пилюля ввода** (поиск, ввод ИИ). Фон `surface-container-low`, радиус 28, без рамки. Слева иконка, справа действия. В фокусе фон белый (в тёмной `#282a2c`) и elevation 1.

**Чипы.** Фильтр — 8, рамка `outline-variant`; выбранный — `primary-container` без рамки, с галочкой. Статусы (Черновик, Идёт сбор, Завершён) — пилюля 24, тональная заливка своего цвета, текст 12 / 500.

**Кнопки.** Primary — синяя заливка. Tonal — `primary-container` («Поделиться», «Улучшить тариф»). Outlined — рамка `outline`. Text — без фона («Отмена» в модалках). Опасная — текст и рамка `error`, заливка только в подтверждении удаления.

**Списки и таблицы.** Шапка таблицы без фона, текст Label `on-surface-variant`. Строки 48, разделитель `#e1e3e1`, наведение `surface-container`, выбрано `primary-container`. Действия строки — ⋮ справа. Пустое состояние — иллюстрация 120, Title M, Body и одна кнопка-пилюля.

**Карточки проектов.** Тональная заливка из пастели NotebookLM (`#fbe9e7`, `#e3f2fd`, `#ede7f6`, `#e8f5e9`, `#fff8e1`); в тёмной теме — те же оттенки 12 % поверх `#1e1f20`. «Новый проект» — белая карточка с кругом «+» `primary-container`.

**Модалки.** Радиус 28, отступ 24, заголовок Title L, кнопки справа внизу: text «Отмена» и primary. Без разделителей. На телефоне — нижний лист на всю ширину.

**Тарифы и оплата.** Сегмент «Месяц / Год» — пилюля, выбранное — синяя заливка. Карточки 24 с рамкой `outline-variant`, рекомендуемая — рамка 2 px `primary` и метка «РЕКОМЕНДУЕМ» Caption синим. Цена Headline 28 / 400. Кнопка покупки на всю ширину. Шаги оплаты — модалка 28 со списком способов (строки 56, радио справа).

**Авторизация.** Канва `#f0f4f9` (тёмная `#131314`), одна карточка 28 шириной до 1040: слева логотип и Headline, справа поля. На телефоне карточка без рамки на весь экран.

## 8. Решение по акценту — принят вариант B (2026-11-09)

Рассматривали два варианта:

- **A.** Синий Google `#0b57d0` на всех действиях, оранжевый только в логотипе.
- **B (выбран).** Форма Gemini (пилюли, поверхности, Google Sans), акцент — тональная палитра оранжевого СВОД.

Поэтому в коде синие роли из раздела 3 заменены оранжевыми, а нейтрали — серые Google, без голубого оттенка:

| Роль | Светлая | Тёмная |
|---|---|---|
| primary | `#c2410c` | `#ffb595` |
| on-primary | `#ffffff` | `#561f00` |
| primary-container (выбранный пункт, тональная кнопка) | `#ffdbcc` | `#4a2412` |
| on-primary-container | `#7a2605` | `#ffdbcc` |
| ссылка | `#9a3412` | `#ffb595` |
| канва / панель / пилюля ввода | `#f8f9fa` / `#ffffff` / `#f1f3f4` | `#131314` / `#1e1f20` / `#282a2c` |
| разделители / рамки | `#e8eaed` / `#dadce0` | `#393b3d` / `#444746` |

Синий `#0b57d0` (в тёмной теме `#a8c7fa`) остаётся только для роли info.

## 9. Перенос в код

1. `src/brand-tokens.css` — значения `--app-*` из раздела 3 и новые токены: `--app-radius-*`, `--app-elevation-*`, `--app-font-display`, `--app-font-text`.
2. `theme.context.tsx` — `token` (colorPrimary, fontFamily, borderRadius 12, borderRadiusLG 16, controlHeight 40) и `components` (Button — пилюля, Modal — 28, Menu — пилюли, Table — шапка без фона, Segmented, Tag, Input).
3. `src/index.css` — шелл (канва + белая панель), сайдбар, шапка, меню (`--app-menu-radius: 16px`, `--app-menu-shadow` = elevation 2).
4. Экраны по очереди: список опросов → «Участники» → оплата `/upgrade/*` → конструктор → авторизация.
