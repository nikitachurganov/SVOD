# Агентный режим СВОД — принятые решения

Дата: 2026-11-05
Статус: решения согласованы, идёт проверка на HTML-прототипе
Прототип: [`docs/prototypes/agent-ui.html`](prototypes/agent-ui.html) · сценарий интервью: [`docs/prototypes/agent-ui-interview.md`](prototypes/agent-ui-interview.md)

Идея: работа с опросом через диалог с ИИ-агентом, как в Claude или ChatGPT. Слева проекты и опросы, по центру чат, справа панель опроса.

---

## 1. Модель

| # | Решение | Отклонённые варианты |
|---|---------|----------------------|
| 1 | **Один опрос — один чат.** Чат нужен только для работы с конкретным опросом. Общих чатов нет, «Новый чат» = «Новый опрос». Сравнение нескольких опросов в агенте не делаем | свободные чаты как в ChatGPT; одна лента на проект |
| 2 | **Чат общий для команды.** Одна лента на опрос, у сообщений автор. Писать может любой участник организации, как сейчас с опросами (`ensure_organization_member`). Токены списываются с отправившего сообщение (`ai_meter`, квота или общий пул по `TEAM_SUBSCRIPTION.md`) | личные ленты; только владелец пишет |
| 3 | **Правки из конструктора и панели** попадают в ленту одной сводкой перед следующим ответом агента: «С прошлого раза: изменён вопрос 3, добавлен вопрос 6 (Аня, 14:20)» | событие на каждое сохранение; не показывать |

## 2. Место в продукте

| # | Решение | Отклонённые варианты |
|---|---------|----------------------|
| 4 | **Агент — дополнительный режим.** Классический интерфейс остаётся главным | агент как главный экран; только агент |
| 5 | **Отдельный полноэкранный режим** со своим сайдбаром «проекты → опросы». Вход: пункт «Агент» в основном меню и «Открыть в агенте» на странице опроса. Выход: «Классический интерфейс». Из панели можно перейти «В конструктор» | раздел внутри текущей оболочки (4 колонки); панель на странице опроса (как `SurveyAiChatPanel`) |
| 6 | **Опрос можно создать без проекта — он попадает в «Черновики».** «Новый опрос» по умолчанию кладёт опрос в «Черновики»; «+» у проекта в сайдбаре — сразу в проект. Место меняется до первого сообщения (меню в поле ввода) или позже — переносом на вкладке «Обзор». *Пересмотрено 2026-11-05: раньше проект был обязателен* | проект обязателен до первого сообщения; агент спрашивает; агент угадывает |

## 3. Агент

| # | Решение | Отклонённые варианты |
|---|---------|----------------------|
| 7 | **Первая версия:** создать, править, анализировать, сделать копию опроса как черновик. **Публикацию и закрытие делает человек** кнопками панели. Отчёт документом и рассылка — во второй версии | агент публикует с подтверждением; всё сразу |
| 8 | **Правка опроса с ответами** по правилам сервера `survey_answers.structure_conflicts`. Разрешено: переформулировать, добавить вопрос, добавить вариант. Агент применяет после подтверждения и предупреждает, что прежние ответы нового вопроса не содержат. Запрещено (409 `survey_structure_locked`): удалить вопрос, сменить тип, удалить вариант. Агент отказывает и предлагает копию как новый черновик | агент не трогает опросы с ответами; версии опроса |
| 9 | **Пишут свободным текстом,** под капотом одна модель с инструментами (`build_survey`, `edit_survey`, `analyze`, `copy_survey`). Под ответами подсказки, при неясном намерении агент переспрашивает | переключатель режимов «Правка / Анализ» |
| 10 | **Реалтайм и очередь.** Поток через SSE, отправка обычным `POST`. Один запуск агента на опрос, остальные видят «Агент отвечает Ане» | опрос сервера раз в 5–10 с; без блокировки |
| 11 | **Согласие на передачу данных ИИ** запрашивается до первого сообщения агенту, как в продукте (`AiConsentModal`, один раз на опрос) | — |

## 4. Правая панель

| # | Решение | Отклонённые варианты |
|---|---------|----------------------|
| 12 | **Вкладки продукта:** «Обзор», «Вопросы», «Ответы», «Аналитика» (`SurveyOverviewTab`, `SurveyFormTab`, `SurveyResponsesTab`, `SurveyAnalyticsTab`), доработанные под колонку 440px с кнопкой «развернуть». Аналитика по методике та же, что в классическом интерфейсе. Агент подсвечивает блоки, на которые ссылается | новые компактные блоки только для агента; динамическая панель-артефакт |
| 13 | **Ручной конструктор во вкладке «Вопросы»:** текст вопроса и вариантов, обязательность, порядок, **добавить вопрос выбранного типа, удалить вопрос, добавить и убрать вариант**. Для опроса с ответами правила решения 8: добавлять можно, удалять вопросы и варианты нельзя. Логика, страницы, оформление, смена типа — в классическом конструкторе. Сохранение тем же `PATCH /surveys/{id}`. *Расширено 2026-11-05: раньше добавить вопрос можно было только через агента* | только просмотр; полный конструктор в панели |
| 14 | **Телефон:** сайдбар выезжает сбоку, панель открывается на весь экран | — |

## 6. Что это значит для реализации (после теста)

**Бэкенд**
- Новые сущности: лента опроса (`survey_messages`: автор, роль, текст, вложения: шаги, цитаты, ссылки на блоки) и снимок `pages` на сообщение для сводки изменений.
- В `Survey` добавить `updated_by_user_id`, заполнять при каждом сохранении (конструктор, панель, агент).
- Оркестратор агента: одна модель с вызовом инструментов через OpenRouter поверх `survey_ai_builder` / `survey_ai_analysis_service`. Проверить, что модель надёжно вызывает инструменты на русском.
- Новый инструмент `copy_survey`: копия `pages` в новый черновик того же проекта.
- «Черновики»: `survey.project_id` сейчас `nullable=False` — сделать необязательным (опрос без проекта = черновик) и добавить перенос опроса между проектами (`PATCH /surveys/{id}` с `project_id`). Альтернатива — системный проект «Черновики» на организацию, но тогда он мешается в списках проектов и отчётах.
- Блокировка: один запуск агента на опрос (строка в БД или advisory lock Postgres).
- SSE-эндпоинт ленты опроса. Пока uvicorn один — рассылка в памяти, при нескольких процессах `LISTEN/NOTIFY` Postgres. Redis не нужен.
- nginx: отдельный `location` для потока, `proxy_buffering off`, `proxy_read_timeout` больше нынешних 120 с.
- Учёт токенов через существующий `ai_meter` с пользователя-отправителя; новые `ACTION_*` для действий агента.

**Фронтенд**
- Новый маршрут агентного режима со своим лэйаутом (вне текущего сайдбара).
- Вкладки опроса проверить и доработать под узкую колонку; режим «подсветить блок» по ссылке агента.
- Быстрые правки в «Вопросах»: текст, варианты, обязательность, порядок.
- Кнопки входа: пункт меню «Агент», «Открыть в агенте» на `SurveyViewPage`.

**Открытые вопросы (не блокируют тест)**
- Сколько истории ленты агент держит в контексте (последние N сообщений + сводка + текущее состояние опроса).
- Что агент показывает для неанонимных опросов: `respondent_meta` в цитатах скрывать по умолчанию.
