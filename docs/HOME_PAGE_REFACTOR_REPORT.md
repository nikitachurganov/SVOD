# Главная СВОД Опросы: отчёт о реализации

Дата: 11 ноября 2026 года.

Основание: [согласованное ТЗ](HOME_PAGE_REFACTOR_SPEC.md), включая сохранённый скриншот-референс.

## Реализовано

- Новая главная `/surveys`: приветствие, баннер с локальным SVG-узором, пять недавних исследований, четыре анкеты и пять материалов.
- Сайдбар с командой, поиском, тремя разделами, тарифом владельца, уведомлениями, обучением и профилем; сворачивание и мобильная навигация.
- Полный список `/surveys/studies` с переключением «Мои / Команда», поиском, проектами, статусами, архивом и пагинацией. Состояние хранится в URL.
- Управление проектами `/surveys/projects`: создание, изменение, удаление пустого проекта; сохранены существующие страницы отдельных проектов.
- Общий список исследований: реальные статусы, авторы, проекты, ответы; открытие, редактирование, перемещение и архивирование с подтверждением.
- Каталог `/surveys/templates`, предпросмотр всех вопросов, название и проект перед созданием. Ошибка сохраняет введённые параметры, повторное нажатие во время запроса заблокировано.
- Детерминированные NPS, CSAT, CES и SUS используют существующие блоки сервера, новые идентификаторы и прежние проверки ручного создания. ИИ не вызывается; миграции не нужны.
- Пять локальных статей `/surveys/resources/:slug`. Хлебные крошки, возвраты к проектам и начало обучения обновлены.
- Светлая и тёмная темы, мобильные карточки вместо таблицы, клавиатурное управление и возврат фокуса после диалогов.
- Защита от устаревших ответов при смене команды. Новая оболочка включена только в самостоятельной сборке опросов.

## API

- `GET /survey-templates` — четыре анкеты с назначением и числом вопросов.
- `GET /survey-templates/{template_id}` — страницы, вопросы и методологические метаданные.
- `POST /surveys/from-template` — создаёт черновик через существующий сервис создания и возвращает `SurveyDetail`.

Клиент передаёт идентификатор анкеты, команду, название и необязательный проект. Вопросы строятся сервером. Неизвестный шаблон возвращает 404; отсутствие прав запрещает создание. Прежние API и адреса сохранены.

## Существующие ошибки вне изменений задачи

Общий `npm run lint` останавливается на `docs/c4/build-figjam.js:138`: `return` вне функции. Этот файл не менялся.

Расширенный серверный прогон выполнил 117 тестов: 111 прошли, шесть завершились ошибками старых фикстур. Отдельный запуск неизменённых `tests.test_survey_projects` и `tests.test_survey_service` воспроизвёл те же шесть ошибок: четыре фикстуры создания проекта используют неасинхронный `MagicMock` для вызовов биллинга; две фикстуры приёма ответа не содержат `organization.owner_user_id`. Эти тесты и соответствующие сервисы не изменялись; диагностический лог — `artifacts/home-refactor/backend-existing-tests.log`.

Vite также сообщает о существующих крупных chunks библиотек и географических данных. Оптимизация этих модулей в задачу не включена.
